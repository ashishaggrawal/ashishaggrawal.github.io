Drop image files (PNG, JPG, SVG) referenced by your diary posts in this folder.

From a post in `content/diary/`, reference them exactly like this:

```
![Alt text describing the image](images/your-file.png)
```

The path is relative to the generated post page (`diary/<slug>.html`), so `images/your-file.png` resolves straight to `diary/images/your-file.png` — no extra configuration needed.
